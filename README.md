# 🎓 EduCertify

**EduCertify** is a full-stack Online Learning & Certification Platform built with **Flask, Python, HTML, CSS, JavaScript, and PostgreSQL**.

🌐 **Live:** [educertify.onrender.com](https://educertify.onrender.com/?utm_source=chatgpt.com)

## ✨ Features

* 👨‍🎓 Student dashboard & course enrollment
* 👨‍🏫 Instructor course management
* 👨‍💼 Admin management
* 📚 Modules & lessons
* 📝 Online quizzes and assessments
* 📊 Learning progress tracking
* 🎓 PDF certificate generation
* 🔍 QR-code certificate verification
* 🔐 Role-based authentication
* 📱 Responsive UI
* 🔌 REST-style API

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, Bootstrap
**Backend:** Python, Flask, SQLAlchemy
**Database:** PostgreSQL
**Certificates:** ReportLab + QR Code
**Deployment:** Render

## 🚀 Run Locally

```bash
git clone https://github.com/irahulvashisth01/EduCertify.git
cd EduCertify
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
